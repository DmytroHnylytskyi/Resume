## 🇬🇧 English Overview

Welcome to my software engineering portfolio repository! This monorepo ecosystem contains **4 production-grade full-stack applications** demonstrating expertise in **React 19**, **Next.js 16**, **Three.js (WebGL / GLSL)**, **FastAPI (Async Python)**, **PostgreSQL 16**, **Docker**, and **TypeScript (Strict)**.

---

## 🏛️ Projects Ecosystem

### 1. 🌌 [Aetheria — 3D Portfolio Hub](Aetheria/) (Port `3000`)
> **Interactive 3D WebGL Portfolio Island & Classic CV Landing.**
* **Stack:** Next.js 16 (App Router), React 19, Three.js, React Three Fiber, Zustand 5, TypeScript.
* **Features:** 3D third-person character controller, interactive portals, instant 0ms bilingual switching (EN / UK), dynamic dark/light themes.

### 2. 🏛️ [Forma-3D — 3D Spatial & Room Configurator](Forma-3D/) (Port `3001`)
> **Commercial-grade 3D interior design and architectural space configurator.**
* **Stack:** Next.js 16, React 19, Three.js, R3F, Zustand 5, FastAPI (Async SQLAlchemy 2.0), PostgreSQL 16, Docker.
* **Features:** Raycasting Surface Snapping ($Y = \text{height}$), 125+ GLB model catalog, Unreal Engine 5 fly-cam navigation, real-time material recoloring, GPU memory deallocation.

### 3. 🌐 [TerraScope — 3D Geospatial Intelligence](TerraScope/) (Port `3002`)
> **Real-time 3D planetary visualization and live satellite data platform.**
* **Stack:** Next.js 16, React 19, Three.js, Custom GLSL Shaders, FastAPI, aiosqlite, Docker.
* **Features:** Custom Day/Night Terminator GLSL shader, GPU Instanced layers (USGS Earthquakes, OpenSky Flights, Open-Meteo Weather, NASA Asteroids), Cache Stampede protection (`asyncio.Lock`).

### 4. 🎓 [Lumina — Asynchronous LMS Platform](Lumina/) (Port `3003`)
> **Enterprise-grade asynchronous educational management platform.**
* **Stack:** React 19, Vite, TanStack Query v5, FastAPI, Async SQLAlchemy 2.0, PostgreSQL 16, Alembic, Docker.
* **Features:** Non-blocking async backend, Optimistic UI updates, JWT access/refresh token rotation, deadline scheduling, homework submission pipeline, Recharts analytics.
