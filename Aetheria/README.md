## 🇬🇧 English Version

### 📌 Overview

**Aetheria** is an interactive, gamified 3D WebGL developer portfolio and multi-project hub built with **Next.js 16 (App Router)**, **React 19**, **Three.js (React Three Fiber & Drei)**, **Zustand 5**, and **Strict TypeScript**.

It features a dual-experience architecture:
1. **Interactive 3D Archipelago:** Explore a floating island environment using third-person avatar navigation (WASD / Arrow keys), interact with knowledge statues, and traverse portals to live demo applications (**Forma-3D**, **TerraScope**, **Lumina**).
2. **Classic Web Resume Landing:** A responsive, accessible, and high-conversion CV view tailored for hiring managers and recruiters.

---

### ✨ Key Features

- **🎮 3D Character Controller & Spatial Interaction:** Smooth avatar movement, jump physics, proximity `[E]` interaction prompts, and 3D portals.
- **🌐 Instant 0ms Bilingual System (EN / UK):** Real-time language toggling without re-rendering or unmounting the 3D WebGL canvas.
- **🎨 Glassmorphism & Theme Switching:** Dynamic Dark / Light theme support with CSS Custom Properties and backdrop-filter glass panels.
- **📜 Verified Credentials & Interactive Modals:** Biography, verified HackerRank certifications, KPI Software Engineering education details, and direct contact gateways.

---

### 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start Next.js development server
npm run dev
```

* **Frontend Application:** [http://localhost:3000](http://localhost:3000)

## 🇺🇦 Українська Версія

### 📌 Опис Проєкту

**Aetheria** — це інноваційне гейміфіковане 3D-портфоліо та головний хаб проєктів розробника, створений на базі **Next.js 16 (App Router)**, **React 19**, **Three.js (React Three Fiber)**, **Zustand 5** та **TypeScript**.

Додаток підтримує два режими перегляду:
1. **Інтерактивний 3D-Острів:** Дослідження 3D-світу персонажем від третьої особи (WASD), взаємодія зі статуями інформації та 3D-портали до реальних проєктів (**Forma-3D**, **TerraScope**, **Lumina**).
2. **Класичний Резюме-Лендінг:** Елегантна, високопродуктивна версія резюме для рекрутерів та технічних лідів.

---

### ✨ Ключові Можливості

- **🎮 Контролер Персонажа та 3D-Взаємодія:** Плавне переміщення (WASD), стрибки, підказки взаємодії `[E]` та 3D-портали переходу на проєкти.
- **🌐 Миттєва Двомовність (UK / EN):** Перемикання мови інтерфейсу за 0 мс без перезавантаження сцени.
- **🎨 Теми Оформлення:** Повноцінна підтримка темної та світлої теми на базі CSS-змінних.
- **📜 Підтверджені Сертифікати:** Інформація про освіту (КПІ «Інженерія ПЗ») та верифіковані сертифікати HackerRank.
